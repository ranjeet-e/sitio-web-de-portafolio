Python · PyTorch · open source · MIT

TokenCraft (tokencraft-gpt)

An educational decoder-only GPT language model implemented from scratch with PyTorch and published on PyPI. It helps learners see tokenization, embeddings, attention, training, and text generation working end to end.

pip install tokencraft-gpt
v0.1.1released Oct 31, 2026Python 3.10+MIT license
What’s inside
  • Tokenizer and token IDs
  • Token, positional, and combined input embeddings
  • Causal self-attention with query, key, and value projections
  • Multi-head attention, feed-forward network, and transformer blocks
  • Next-token training and autoregressive generation

It’s an educational project, not a pretrained chatbot, and the README says so plainly.

  • Python
  • PyTorch
  • Transformers
  • Attention

iLoveSwap (doc-standardizer)

A private document tool that updates details across PDF and Word files in one click. It detects text sections, replaces outdated titles, dates, or contact details, and exports standardized files while preserving layout—locally on your device.

git clone https://github.com/ranjeet-e/iLoveSwap.git
v1.0.0100% private · no cloud uploadsbatch processingfree & open source
What’s inside
  • Private & secure — files stay on your device
  • PDF & Word — work with .pdf and .docx
  • Layout preservation — maintain tables, fonts, images, and charts
  • Batch updates — apply one change across multiple documents
  • Click-to-edit — select text to update or erase
